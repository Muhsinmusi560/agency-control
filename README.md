# Agency Control

A phone-friendly dashboard to manage hometown shoots and promotions (hotels, restaurants, brands) from anywhere. Assign tasks, track progress, and send WhatsApp briefings to the team.

## Publish on GitHub Pages
1. Create a new repository on GitHub (for example `agency-control`).
2. Upload `index.html`, `.nojekyll` and `README.md` to the repository's main branch.
3. Open Settings, then Pages. Under "Build and deployment", choose "Deploy from a branch", branch `main`, folder `/ (root)`, and Save.
4. After a minute the site is live at `https://<your-username>.github.io/agency-control/`.

## Notes
- Data is stored in the browser on the device you use, so open the same link on the same phone each time.
- WhatsApp buttons open a ready-to-send message; the sender presses send.
